# Assets Directory

This directory contains static assets for the bot.

## Logo Files

Place your logo files here:
- `logo.png` - Bot logo for video watermarking
- `logo.jpg` - Alternative logo format

## Watermark Configuration

The watermark processor will look for logo files in this directory.
If no logo file is found, text watermark will be used instead.

## Text Watermark

Default text watermark: "@uzkinobaza_bot"

You can customize this in the watermark processor configuration.
